# 安全与分享检查

- `.env` 已被忽略，分享包只包含 `.env.example`。
- DeepSeek、Qwen、数据库和 n8n 密钥必须由每位使用者自己配置。
- 不要截图或复制完整 API Key 到聊天、Issue、Git 提交和 n8n 节点参数。
- `uploads/` 可能包含论文全文与图片，不应公开提交。
- `data/` 和 Docker volumes 可能包含用户账号、论文、n8n 执行记录和缓存，不应公开提交。
- n8n 与 renderer-api 在生产环境中应只允许网站后端访问；本分享包仅将管理端口绑定到本机。
- 公开部署时使用 HTTPS、持久化数据库、对象存储、访问控制、速率限制和定期执行记录清理。
- 正式发布图片前仍需人工审核科学事实、原图版权和 AI 风险。
